# План проверок перед первым полётом

**Во время стендовых проверок пропеллеры должны быть сняты.**

## 1. Сохранить конфигурацию
- [ ] Подключиться к правильному COM-порту.
- [ ] Подтвердить версию прошивки и target в INAV Configurator.
- [ ] Сохранить свежие `dump` и `diff all` с датой.
- [ ] Не использовать старые Betaflight-дампы как текущие настройки INAV.

## 2. Модель и моторы
- [ ] В Setup проверить, что 3D-модель правильно повторяет крен, тангаж и рыскание рамы.
- [ ] В Motors кратко проверить выходы M1–M4 по одному на безопасном уровне.
- [ ] Сопоставить физические моторы с номерами выходов и схемой Quad X.
- [ ] Проверить направление вращения каждого мотора; исправлять только известным способом для установленного ESC.

## 3. Аппаратура и failsafe
- [ ] Проверить каналы и диапазоны в Receiver.
- [ ] Подтвердить назначение ARM и режимов.
- [ ] Записать значения failsafe из актуальной конфигурации.
- [ ] С пропеллерами снятыми проверить распознавание потери сигнала и поведение выходов моторов по процедуре INAV.

## 4. Питание и механика
- [ ] Проверить полярность, пайку, разъёмы и отсутствие короткого замыкания.
- [ ] Убедиться в соответствии питания ESC и компонентов.
- [ ] Перед полётом использовать исправную подходящую батарею; проверить просадку напряжения.

## 5. Перед первым полётом
- [ ] Все предыдущие проверки завершены без ошибок.
- [ ] Пропеллеры установлены по схеме Quad X и правильному направлению вращения.
- [ ] Первый тест проводить на открытой площадке вдали от людей, животных, дорог и препятствий.
- [ ] GPS/RTH добавлять позже, после устойчивого базового полёта.

Записывайте дату, версию INAV, действие и результат. Не подтверждённое отмечайте «не проверено».
