# OMNIBUS F4 + INAV 10.0.0 — предварительная контрольная точка

## Конфигурация
- Контроллер: OMNIBUS F4SD / STM32F405.
- Цель платы: `OMNIBUSF4V3`.
- Прошивка: INAV 10.0.0 по текущим сведениям; точную установленную сборку нужно подтвердить в Configurator.
- ESC: LANRC MAK4 4-in-1.
- Моторы: RS2212 920KV.
- GPS и RTH отложены до подтверждения устойчивого базового полёта.

## Подтверждено пользователем
- Все четыре мотора работают.
- Обороты плавно меняются с аппаратуры.
- ARM работает после включения в INAV Motors пункта «Включить выходы двигателя и сервопривода».
